================================================================================
Phase 7: MCP (Model Context Protocol) ❌ NOT NEEDED
================================================================================

❌ MCP Server/Client implementation - SKIPPED

Reason: Agentic RAG provides equivalent functionality:
- LLM Router replaces MCP tool selection
- Direct API calls replace MCP tool invocations
- Simpler architecture, fewer dependencies
- Same capabilities without MCP overhead

The Agentic RAG pattern in chat_service.py achieves:
- search_knowledge_base → Vector search in knowledge_base collection
- search_products → Vector search + Spring Boot API enrichment
- get_product_details → Direct call to /internal/ai/products/{id}
- get_supplier_info → Direct call to /internal/ai/suppliers/{id}
- get_inventory_status → Direct call to /internal/ai/inventory/{id}

FINAL API STRUCTURE SUMMARY
================================================================================

Channel A: Frontend ↔ Spring Boot (Public API)
----------------------------------------------
GET  /api/v1/chat/sessions                    - List user's sessions
POST /api/v1/chat/sessions                    - Create new session
GET  /api/v1/chat/sessions/{sessionId}/messages - Get messages
POST /api/v1/chat/sessions/{sessionId}/messages - Ask question

GET  /api/v1/products/{productId}/recommendations - Similar products
GET  /api/v1/recommendations/homepage            - Homepage recs
GET  /api/v1/recommendations/user                - User recs

POST /api/v1/analytics/track                     - Track interaction

Channel B: Spring Boot ↔ Python AI Service (Internal)
------------------------------------------------------
POST   /ai/ingest/product        - Ingest product to vector DB
POST   /ai/ingest/products/bulk  - Bulk ingest products
POST   /ai/ingest/document       - Ingest knowledge document
DELETE /ai/ingest/product/{sku}  - Remove product from vector DB

POST /ai/chat/generate           - Generate AI response (Agentic RAG)
POST /ai/chat/classify           - Classify query type

POST /ai/recommend/analytics/track - Track for recommendations
GET  /ai/recommend/user/{userId}   - Get user recommendations
GET  /ai/recommend/similar/{productId} - Get similar products
GET  /ai/recommend/homepage        - Get homepage recommendations

Channel C: AI Service → Spring Boot (Data Enrichment)
------------------------------------------------------
GET /internal/ai/products/{id}     - Get product details
GET /internal/ai/products/search   - Search products with filters
GET /internal/ai/suppliers/{id}    - Get supplier info
GET /internal/ai/inventory/{id}    - Get inventory status
